# Mixmetry

PWA для расчёта автополива и приготовления питательного раствора для растений.

## Возможности

- расписание поливов с учётом светового окна;
- расчёт расхода компенсированных капельниц и запаса бака;
- календарное напоминание о следующем наполнении;
- коллекция базовых удобрений и добавок;
- расчёт рецепта по среде, стадии растения и объёму воды;
- светлая, тёмная и системная темы;
- мобильная навигация и переключение страниц свайпом;
- установка как PWA и работа ранее загруженной версии без сети.

> Дозировки носят справочный характер. Перед применением сверяйтесь с актуальной инструкцией производителя и учитывайте качество воды, субстрат и состояние растений.

## Требования

- Node.js 20;
- npm 10 или новее.

## Локальная разработка

```bash
npm ci
npm run dev
```

Vite слушает все сетевые интерфейсы на порту `5173`. Базовый путь приложения — `/DripCalc/`.

## Проверка релизной сборки

```bash
npm run check
npm run test:e2e
```

`check` последовательно запускает ESLint, unit-тесты и production-сборку. E2E-тесты сами собирают приложение и поднимают локальный preview-сервер.

## Production preview

```bash
npm run build
npm run preview -- --host 0.0.0.0
```

Содержимое `dist/` воспроизводимо создаётся из lock-файла через `npm ci && npm run build`.

## Деплой

Workflow `.github/workflows/deploy.yml` проверяет lint, unit-тесты и сборку, после чего публикует `dist/` в GitHub Pages при обновлении ветки `main`. В настройках репозитория источником Pages должен быть выбран **GitHub Actions**.

## Ограничения

- Интерфейс релизной версии доступен на русском языке. Английская локализация будет возвращена после полного перевода всех сценариев.
- Проверка библиотеки гарантирует техническую целостность записей, но не заменяет предметную проверку таблиц питания.
- На некоторых версиях iOS установленная PWA может получать от WebKit область viewport меньше физического экрана; системная зона находится вне DOM приложения.
