# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии Mixmetry.

## Сообщение об уязвимости

Не публикуйте сведения о потенциальной уязвимости в открытом issue.

Используйте приватный канал **Security → Report a vulnerability** в репозитории GitHub. Укажите затронутую версию, шаги воспроизведения, возможное влияние и, если возможно, безопасный вариант исправления.

Мы подтвердим получение сообщения и сообщим о дальнейших шагах после первичной проверки. Публичное раскрытие следует согласовать после выпуска исправления.

## Область действия

Политика относится к приложению Mixmetry, его GitHub Pages-сборке и workflow публикации. Данные о дозировках носят справочный характер и не являются вопросами информационной безопасности.
